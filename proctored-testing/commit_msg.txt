fix(mobile): resolve critical android constraints and performance bottlenecks

- Core Layout & Viewport:
  - Added missing <meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover"> to layout.tsx to prevent desktop scaling on Android Chrome.
  - Added theme-color meta tag for Android Chrome toolbar consistency.
  - Migrated 100vh to 100dvh in waiting-room/page.tsx, student-dashboard/page.tsx, and test/page.tsx gates to prevent start buttons and key UI from being clipped behind the dynamic Android bottom navigation bar.

- Camera & Media Management:
  - Enforced facingMode: { ideal: 'user' } in getUserMedia to guarantee front-camera usage, preventing default rear-camera selection by OEMs like Samsung/Xiaomi.
  - Mitigated NotReadableError on Huawei/Xiaomi devices by reusing the parent MediaStream's audio track rather than instantiating a second concurrent stream in ProctoringMonitor.
  - Addressed Android Web Audio Autoplay Policy by explicitly calling await audioCtx.resume() after context creation, ensuring mic reads don't fail silently.

- Performance & Reliability (ProctoringMonitor):
  - TF.js Fallback Chain: Implemented webgl -> wasm -> cpu fallback loop to prevent hard crashes on mid-range Android GPUs that lack VRAM.
  - OOM Prevention: Skipped COCO-SSD model loading entirely when isMobile is detected, as phone detection is moot on mobile and dual-model loading (FaceMesh + COCO) crashes low-RAM devices (<= 3GB).
  - Addressed visibilitychange false positives (triggered by keyboard popups and notification shades) by doubling the TAB_SWITCHED threshold buffer on mobile devices.
  - Guarded canvas.filter calls with feature detection to prevent TypeError crashes in legacy Android WebView and Samsung Internet.

- Exam Resiliency:
  - Integrated Screen Wake Lock API in test/page.tsx to prevent device screen timeouts mid-exam, avoiding inadvertent TAB_SWITCHED violations.
  - Countdown Timer drift: Refactored CountdownTimer.tsx from standard setInterval decrements to a Date.now() wall-clock delta calculation to prevent timer desync when Android throttles CPU cycles.
